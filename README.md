# Wholesome Habits — 21-Day Transformation Programme

A responsive wellness and fitness landing website for the **Wholesome Habits 21-Day Transformation Programme**.

The website is designed to help visitors understand the programme, explore its benefits, and register directly through WhatsApp.

## 🌿 About the Programme

Wholesome Habits is a guided 21-day transformation programme focused on building simple, sustainable habits around:

- 🥗 Nourishing Nutrition
- 🧘 Daily Habit Building
- 💧 Mindful Wellness
- 🏋️ Movement & Fitness
- ❤️ Better Energy & Lifestyle

The goal is to encourage small, consistent actions that can create meaningful long-term change.

## ✨ Website Features

- Responsive desktop and mobile design
- Wholesome Habits branded landing page
- 21-Day Transformation Programme hero section
- Programme benefits
- How the programme works
- Testimonials / success stories
- FAQ section
- Coach / nutritionist information
- WhatsApp contact integration
- Registration form
- Automatic WhatsApp message generation after registration
- Mobile-friendly navigation
- Client programme images and promotional content

## 📱 WhatsApp Integration
